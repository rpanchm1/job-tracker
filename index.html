How to sync across devices

By default your data is saved in this browser only. To access it on any device, connect a sync file stored in Google Drive, OneDrive, or Dropbox.

First device (setup)
  1. Click the Local only pill in the top-right
  2. Click Create a new sync file
  3. Save it inside your Google Drive / OneDrive folder
  4. The dot turns green — you're synced ✓
Other devices
  1. Wait for Google Drive / OneDrive to sync the file
  2. Open this site and click Local only
  3. Click Open existing sync file
  4. Select the same file from your cloud folder

⚠ Sync requires Chrome or Edge. Firefox is not supported.
